# Changelog

## 1.0.0 — 2026-09-10

First release of Blackout for macOS 26 and later.

- Cover any selected display, including the primary or only monitor.
- Choose pure black or a Tahoe-inspired lock screen with a custom wallpaper.
- Toggle covers with a configurable global shortcut, defaulting to Control–Option–Command–B.
- Hide the pointer over covers and omit the lock-screen shortcut hint.
- Accept masked decorative password input while declining every entry; entered text is never retained.
- Remember display selections, wallpaper, appearance, and shortcut across launches.
- Uncover on sleep and always start uncovered.

The app is ad-hoc signed and is not notarized. Covers provide visual privacy, not macOS session authentication. Mirrored displays cannot be covered independently. See VALIDATION.md for hardware checks still awaiting manual verification.
